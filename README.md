# Car Deal Finder

A beginner Python project that helps analyse car deals and calculate potential profit.

## Features

- Add car deals
- Calculate profit
- Rate deals
- Search saved deals
- Delete deals
- Sort deals
- View statistics
- Export reports

## Skills Used

- Python variables
- Functions
- If statements
- Loops
- Lists and dictionaries
- File handling
- Sorting
- Debugging

## How to Run

Open the project in VS Code and run:

```bash
python main.py
```
